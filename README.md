# Aviral Gupta — Manager Feedback

Quarterly manager performance evaluations, most recent first. Linked from my résumé.

**Live:** https://aviralgupta752.github.io/Aviral-Resume/

## How it works

`index.html` is generated by [`build.mjs`](build.mjs) from the review screenshots
in [`images/`](images/) (auto-discovered) plus a little profile data in
`build.mjs`. The GitHub Action ([`.github/workflows/deploy.yml`](.github/workflows/deploy.yml))
runs `node build.mjs` and deploys to GitHub Pages on every push to `main`.

Local preview:

```bash
node build.mjs && open index.html
```

## Adding a new quarter

1. Add the screenshot to `images/` named `fy<FY>-q<Q>.png` — e.g. `fy27-q2.png` (no number prefix).
2. (Optional) add a short pulled quote in `REVIEW_META` in `build.mjs`.
3. Commit & push. The new quarter sorts to the top automatically. To star it as a standout, add its stem (e.g. `fy27-q2`) to the `HIGHLIGHT` array in `build.mjs`.
