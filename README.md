# Aviral Gupta — Portfolio

A minimalist one-page portfolio: projects & impact, quarterly manager feedback,
skills, experience, and a bit of personal life.

**Live:** https://aviralgupta752.github.io/Aviral-Resume/

## How it works

`index.html` is generated by [`build.mjs`](build.mjs) from:
- the content data at the top of `build.mjs` (profile, projects, skills, experience, interests), and
- the manager-review screenshots in [`images/`](images/), which are auto-discovered.

The GitHub Action ([`.github/workflows/deploy.yml`](.github/workflows/deploy.yml))
runs `node build.mjs` and deploys to GitHub Pages on every push to `main`, so the
site always matches the repo.

Local preview:

```bash
node build.mjs && open index.html
```

## Adding a new quarter's feedback

1. Add the screenshot to `images/` named `fy<FY>-q<Q>.png` — e.g. `fy27-q2.png` (no number prefix).
2. (Optional) add a short pulled quote in `REVIEW_META` in `build.mjs`.
3. Commit & push. The new quarter sorts to the top automatically, and the latest 3 quarters are highlighted.
